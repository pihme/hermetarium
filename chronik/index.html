Chronicles

The history of Hermetarium as set down so far, newest first.

October 2026

Early in the month a humble brother taught the release script to honour a Release-As footer and to keep versions below 1.0 until asked. Later the strong wall learned to take its memory and disk size at creation, the helper image came under Dependabot's watch, and the hello-world example gained an image of its own. These came together in hermetarium v0.5.0. A security review before 1.0 turned on code scanning, and the test suite was described in a list of its own. The brothers then listed the third-party software it carries in notices attached to each release, and in the middle of the month the project received its logo. The project still has two stars.

September 2026

Early in the month Hermetarium was given a home on GitHub, and a first star came a few days later. Mid-month came the main work: inbound HTTP through Squid, the same OCI image booting on Firecracker, examples, and templates for the official coding CLIs with their adapter, porter. v0.1.0 and porter v0.1.0 were released, and the next day v0.4.0 brought create --acl. A second star followed. Late in the month Fregoli was named as a possible inhabitant, this website was set up, and Dependabot began to keep watch.

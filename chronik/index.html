Chronicles

The history of Hermetarium as set down so far, newest first.

September 2026

In the ninth month of the year of our Lord 2026, upon the sixth day, the house of Hermetarium was raised upon GitHub and its first commit laid down; upon the tenth day it received its first star. The great labour came upon the fifteenth day: a CI workflow, inbound HTTP through Squid with the echo example, the selfsame OCI image made to boot upon Firecracker, coding-agent examples, and dwellings for the official coding CLIs together with porter, their adapter. That night create learned to take any OCI image by --image, the README was written anew and a usage guide added, and the first releases went forth: hermetarium v0.1.0 and porter v0.1.0, and but minutes later v0.2.0 with the Go module path and contributing docs. Upon the sixteenth day v0.3.0 had Squid drawn as a pulled image, the Firecracker helper scripts embedded within, and XDG directories used outside a checkout; and after a refactor that left but a single agentd example, v0.4.0 brought forth create --acl, each habitat keeping its Squid wall config beside its Dockerfile. That same evening the scribes set right what was written of DeepSeek Harness (dsh) session continuity, and porter tests were added. Upon the seventeenth day a second star was given. Upon the twenty-fifth day a refactor brought the ACL, probe and docs into accord with the copied --acl file; and upon the twenty-sixth the scribes named Fregoli as one who might dwell within, whilst this website was raised upon GitHub Pages and that same day gained a sidebar, a drawing of its architecture, and these chronicles.

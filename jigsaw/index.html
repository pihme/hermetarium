Jigsaw

Hermetarium is one piece of a growing family of projects, big and small. Here is how the pieces fit together, as seen from this one.

H

Hermetarium you are here

Sealed habitat where agents live: they wake up inside an OCI image, may change that world freely, and cannot leave.

F

Fregoli inhabitant

Self-evolving web app on a Cordis kernel: one process, many appearances, plugins that load and unload without a restart.

A would-be tenant from next door. Fregoli is a self-evolving web app whose own Docker image serves HTTP on port 8080 directly, no porter needed, and its docs name Hermetarium as the recommended, though optional, place to run it. It has not moved in yet: its server currently binds 127.0.0.1 only, which likely keeps it unreachable through the wall until fregoli#1 is resolved.
